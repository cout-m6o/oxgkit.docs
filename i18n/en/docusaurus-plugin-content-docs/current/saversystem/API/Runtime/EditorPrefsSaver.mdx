`EditorPrefsSaver` is the built-in **editor saver** of the **SaverSystem** (inherits [Saver](./Saver.mdx)). It uses `UnityEditor.EditorPrefs` as the storage backend and is suited for storing **editor tool preferences** (EditorWindow, custom Inspectors, etc.); the base class [text-content data feature (Data Map)](./Saver.mdx#data-map) is available directly.

|  |  |
| :--- | :--- |
| **Namespace** | `OxGKit.SaverSystem.Editor` |
| **Type** | `public class EditorPrefsSaver : Saver` |
| **Source** | [EditorPrefsSaver.cs](https://github.com/michael811125/OxGKit/blob/master/Assets/OxGKit/SaverSystem/Scripts/Editor/Core/Saver/Implements/EditorPrefsSaver.cs) |

```csharp
using OxGKit.SaverSystem;
using OxGKit.SaverSystem.Editor;
```

<Highlight color="#ff2f00">Important</Highlight> `EditorPrefsSaver` lives in the **Editor Assembly** (`OxGKit.SaverSystem.Editor`) and can **only be referenced from editor scripts (Editor folders or Editor asmdefs)** — never from runtime scripts (builds would fail to compile).

## Quick Start {#quick-start}

```csharp
using OxGKit.SaverSystem;
using OxGKit.SaverSystem.Editor;

// Create a saver in an editor tool (EditorPrefs backend)
Saver editorSaver = new EditorPrefsSaver();

// Store editor tool preferences
editorSaver.SaveString("MyProject.MyTool.lastExportPath", "Assets/Exports");
string path = editorSaver.GetString("MyProject.MyTool.lastExportPath", "");
```

## General Rules {#general-rules}

### Scope {#scope}

| Saver | Storage Backend | Scope |
| :--- | :--- | :--- |
| [PlayerPrefsSaver](./PlayerPrefsSaver.mdx) | `UnityEngine.PlayerPrefs` | **Runtime** (in-game settings, stored per application/platform) |
| `EditorPrefsSaver` | `UnityEditor.EditorPrefs` | **Editor only** (editor tool preferences) |

(See the [Module Intro](../../intro.mdx) for an overview)

### Storage Scope and Write Timing {#storage-scope}

<Highlight color="#0373fc">Attention</Highlight> `EditorPrefs` is **user-level** storage, **shared by ALL Unity projects on the same machine** — prefix keys with a project or tool name (e.g., `MyProject.MyTool.someKey`) to avoid collisions.

<Highlight color="#00d679">Reminder</Highlight> Unlike [PlayerPrefsSaver](./PlayerPrefsSaver.mdx), `EditorPrefs` is **persisted automatically by the editor** — there is no (and no need for a) `Save()` call.
