`PlayerPrefsSaver` is the built-in **runtime saver** of the **SaverSystem** (inherits [Saver](./Saver.mdx)). It uses `UnityEngine.PlayerPrefs` as the storage backend, and every `Save*` automatically calls `PlayerPrefs.Save()` to **write immediately**; the base class [text-content data feature (Data Map)](./Saver.mdx#data-map) is available directly.

## Quick Start {#quick-start}

```csharp
using OxGKit.SaverSystem;

// Create a runtime saver (PlayerPrefs backend)
Saver saver = new PlayerPrefsSaver();

// Basic access
saver.SaveString("name", "michael");
saver.SaveInt("language", 2);
saver.SaveFloat("bgmVolume", 0.8f);

// Text-content data feature (provided by the Saver base class)
saver.SaveData("appPrefs", "lastLogin", "2026-07-29");
string lastLogin = saver.GetData("appPrefs", "lastLogin", null);
```

## General Rules {#general-rules}

### Scope {#scope}

| Saver | Storage Backend | Scope |
| :--- | :--- | :--- |
| `PlayerPrefsSaver` | `UnityEngine.PlayerPrefs` | **Runtime** (in-game settings, stored per application/platform) |
| [EditorPrefsSaver](./EditorPrefsSaver.mdx) | `UnityEditor.EditorPrefs` | **Editor only** (editor tool preferences) |

(See the [Module Intro](../../intro.mdx) for an overview)

### Write Timing {#write-timing}

<Highlight color="#0373fc">Attention</Highlight> Every `Save*` automatically calls `PlayerPrefs.Save()` to write to disk immediately; [DeleteKey](#deletekey) / [DeleteAll](#deleteall) do **not** call `Save()` additionally (by Unity default they are written on normal application quit — call `PlayerPrefs.Save()` yourself if needed).

<Highlight color="#00d679">Reminder</Highlight> The `PlayerPrefs` storage location differs per platform (e.g., the registry on Windows, browser IndexedDB on WebGL); on **WebGL** persistence relies on the browser flushing, and **avoid storing huge strings**.
