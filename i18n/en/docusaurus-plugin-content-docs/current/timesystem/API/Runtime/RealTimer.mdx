`RealTimer` is a **real-time timer counted by the system clock (`DateTime.Now`)**, using the moment of instance creation as its time base. It is **query-based and self-driven (no external Update feeding required)**, and is unaffected by `Time.timeScale`, game pause, or frame stalls. It supports the **Timer (one-shot)**, **Tick (repeating)**, and **Mark (time anchor)** modes plus time-speed adjustment.

## Quick Start {#quick-start}

```csharp
using OxGKit.TimeSystem;
using UnityEngine;

public class RealCooldown : MonoBehaviour
{
    private RealTimer _cooldown;

    private void Start()
    {
        // Create and auto play (autoPlay: true)
        this._cooldown = new RealTimer(true);
        // Set a 10-second cooldown (real time)
        this._cooldown.SetTimer(10f);
    }

    private void Update()
    {
        // Query-based check, no deltaTime feeding needed
        if (this._cooldown.IsTimerTimeout())
        {
            // Cooldown finished (counts down even while Time.timeScale = 0)
        }
    }
}
```

## General Rules {#general-rules}

### RealTimer vs DeltaTimer {#realtimer-vs-deltatimer}

<Highlight color="#0373fc">Attention</Highlight> A `RealTimer` counts by the **system clock** — it **keeps counting even while the game is paused (`Time.timeScale = 0`) or the app stalls**. For timing that should follow game pause and speed changes, use a [DeltaTimer](./DeltaTimer.mdx) instead (see [Picking the Right Tool](../../intro.mdx#picking-the-right-tool-by-time-base)).

### Playback State {#playback-state}

<Highlight color="#ff2f00">Important</Highlight> A timer is **stopped by default after construction** — call [Play](#play) (or use the `autoPlay: true` constructor) to start counting.

<Highlight color="#00d679">Reminder</Highlight> [Stop](#stop) clears all timing data (keeps the time speed); [Reset](#reset) also resets the time speed back to its default; [Pause](#pause) only pauses and can be resumed with [Play](#play).

### GetRealTime {#getrealtime}

```csharp
public float GetRealTime()
```

Gets the real seconds elapsed **since the timer instance was created** (computed from the system clock `DateTime.Now`, unaffected by the playback state and time speed).

### Play {#play}

```csharp
public void Play()
```

Starts counting, or **resumes** from a paused state (the paused real-time span is deducted — the time does not jump).

### Pause {#pause}

```csharp
public void Pause()
```

Pauses counting and records the pause point; resumable with [Play](#play).

### Stop {#stop}

```csharp
public void Stop()
```

Stops counting and **clears all timing data** (Timer / Tick / Mark settings are zeroed), but **keeps the time speed** (timeSpeed).

### Reset {#reset}

```csharp
public void Reset()
```

Resets all state to defaults (including **resetting the time speed to 1**) and returns to the stopped state.

### IsPlaying {#isplaying}

```csharp
public bool IsPlaying()
```

Returns whether the timer is currently counting.

### IsPause {#ispause}

```csharp
public bool IsPause()
```

Returns whether the timer is paused (not playing).

### GetTime {#gettime}

```csharp
public float GetTime()
```

Gets the timer's **current accumulated time (seconds)**; while counting it is affected by [SetTimeSpeed](#settimespeed), and while paused it returns the time at the pause point.

### SetTimeSpeed {#settimespeed}

## Timer (One-Shot) {#timer}

A **one-shot countdown** based on the configured seconds.

### Method Overview {#timer-overview}

| Method | Description |
| :--- | :--- |
| [SetTimer](#settimer) | Sets the seconds to count. |
| [TimerCountdown](#timercountdown) | Gets the remaining seconds (0 when reached). |
| [IsTimerTimeout](#istimertimeout) | Returns whether the timer has reached its time. |
| [GetTimerCountdownRatio](#gettimercountdownratio) | Gets the countdown ratio (1 decreasing to 0). |

---

### SetTimer {#settimer}

```csharp
public void SetTimer(float timeSeconds)
```

Sets the seconds to count (current time + seconds becomes the trigger point).

```csharp
this._realTimer.SetTimer(10f);
this._realTimer.Play();
```

### TimerCountdown {#timercountdown}

```csharp
public float TimerCountdown()
```

Calculates the remaining seconds until the trigger point; returns 0 directly once the trigger time has been exceeded.

### IsTimerTimeout {#istimertimeout}

```csharp
public bool IsTimerTimeout()
```

Returns whether the timer has reached its time (true once past the trigger point).

<Highlight color="#00d679">Reminder</Highlight> After the time is up, `IsTimerTimeout()` **keeps returning true** — for one-shot behavior, call [Stop](#stop) or a new [SetTimer](#settimer) after handling the trigger.

### GetTimerCountdownRatio {#gettimercountdownratio}

```csharp
public float GetTimerCountdownRatio()
```

Gets the countdown ratio of the Timer, **from 1 decreasing to 0, where 0 = time's up** (handy for progress-bar UI).

## Tick (Repeating) {#tick}

Fires **repeatedly** at the configured interval (re-arms automatically after each timeout).

### Method Overview {#tick-overview}

| Method | Description |
| :--- | :--- |
| [SetTick](#settick) | Sets the Tick interval in seconds. |
| [GetTick](#gettick) | Gets the configured Tick interval. |
| [TickCountdown](#tickcountdown) | Gets the remaining seconds of the current Tick. |
| [IsTickTimeout](#isticktimeout) | Returns whether the Tick is due (auto re-arms). |
| [GetTickCountdownRatio](#gettickcountdownratio) | Gets the Tick countdown ratio (1 decreasing to 0). |

---

### SetTick {#settick}

```csharp
public void SetTick(float tickSeconds)
```

Sets the Tick interval in seconds; after [IsTickTimeout](#isticktimeout) fires, the Tick **keeps cycling**.

```csharp
// Fire every 2 seconds (real time)
this._realTimer.SetTick(2f);
this._realTimer.Play();
```

### GetTick {#gettick}

```csharp
public float GetTick()
```

Gets the configured Tick interval in seconds.

### TickCountdown {#tickcountdown}

```csharp
public float TickCountdown()
```

Gets the remaining seconds until the current Tick fires; returns 0 directly once the trigger time has been exceeded.

### IsTickTimeout {#isticktimeout}

```csharp
public bool IsTickTimeout()
```

Returns whether the Tick is due; when it returns true, the next Tick is **automatically re-armed from the current time**, forming a repeating trigger.

```csharp
private void Update()
{
    if (this._realTimer.IsPlaying() &&
        this._realTimer.IsTickTimeout())
    {
        // Fires once per Tick cycle
    }
}
```

<Highlight color="#ff2f00">Important</Highlight> When `IsTickTimeout()` returns true it **re-arms automatically**, which "consumes" that trigger — **check it from exactly one caller per cycle**, or the trigger will be eaten by another caller.

### GetTickCountdownRatio {#gettickcountdownratio}

```csharp
public float GetTickCountdownRatio()
```

Gets the Tick countdown ratio, **from 1 decreasing to 0, where 0 = time's up**.
