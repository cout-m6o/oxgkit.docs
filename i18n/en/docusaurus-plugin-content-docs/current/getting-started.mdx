**Installing OxGKit**

<Highlight color="#0373fc">Attention</Highlight> OxGKit systems are **all standalone tools** — there is no need to install everything at once. **Install only what you need**, along with the dependencies required by those modules.

## Step 1. (Install Dependencies)

**Based on the modules you plan to install**, install their third-party dependencies first (see the [dependency notes in Step 2](#install-modules)).

- <Highlight color="#ff2f00">1</Highlight> **[UniTask](https://github.com/Cysharp/UniTask)** (required by InfiniteScrollView, ActionSystem, TimeSystem, PoolSystem, Utilities)

Install via Package Manager **(Install via git)**

```
https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask
```

- <Highlight color="#ff2f00">2</Highlight> **[LWMyBox](https://github.com/michael811125/LWMyBox)** (required by LoggingSystem, TweenSystem, PoolSystem, Utilities)

Install via Package Manager **(Install via git)**

```
https://github.com/michael811125/LWMyBox.git
```

- <Highlight color="#ff2f00">3</Highlight> **[Unity New InputSystem](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.8/manual/index.html)** (required by InputSystem)

Install via Package Manager **(Install by name)**

```
com.unity.inputsystem
```

- <Highlight color="#ff2f00">4</Highlight> **[DoTween Pro](https://assetstore.unity.com/packages/tools/visual-scripting/dotween-pro-32416)** (required by TweenSystem, **must be purchased separately**)

- <Highlight color="#00d679">Reminder</Highlight> **OxGKit.LoggingSystem** is a shared dependency of most modules (InfiniteScrollView, ActionSystem, NoticeSystem, InputSystem, TimeSystem, PoolSystem, Utilities) — **it is recommended to install it first**.

```
https://github.com/michael811125/OxGKit.git?path=Assets/OxGKit/LoggingSystem/Scripts
```

### Method 2

**Download the source directly ([Code Download ZIP](https://github.com/michael811125/OxGKit))**

Copy the folders of the modules you need (Assets/OxGKit/[ModuleName]) into your Unity project's Assets folder.

<Highlight color="#00d679">Reminder</Highlight> **If you don't need to modify the toolkit yourself, installing via Package Manager is recommended.**

## Importing Samples

Every module ships with **Examples** and **AI Agent Skills** — import them via **Package Manager -> select the module -> Samples**.

<Highlight color="#00d679">Reminder</Highlight> There are many ways to call the APIs — check each module's Samples for complete examples.

---

## Build Activation Symbol

- **OXGKIT_LOGGER_ON** (the [LoggingSystem](/docs/loggingsystem/intro) output switch — **for builds, add it to Player Settings -> Scripting Define Symbols or no logs will be output**)

---

## AI-Assisted Development (AI Agent Skills) {#ai-agent-skills}

Every OxGKit system module supports development assisted by **AI coding agents** (Claude Code, OpenAI Codex CLI, Cursor, Copilot, etc.). Each module's Samples include built-in **AI Agent Skills** (SKILL.md) that teach the agent how to use that module's API correctly.

<Highlight color="#0373fc">Attention</Highlight> For the full import and usage guide, see [AI Agent Skills](/docs/agent-skills).
