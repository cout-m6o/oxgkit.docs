`CursorManager` is the **cursor manager** of **CursorSystem** (a `MonoBehaviour` singleton) that manages the [CursorState](#cursorstate) list configured in the Inspector and drives the **frame animation of dynamic cursors** in `Update`. Import the **CursorManager Prefab** via Samples and drop it into the boot scene, or let the [Cursors](./Cursors.mdx) facade create it automatically.

|  |  |
| :--- | :--- |
| **Namespace** | `OxGKit.CursorSystem` |
| **Type** | `[DisallowMultipleComponent] public class CursorManager : MonoBehaviour` |
| **Source** | [CursorManager.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/CursorSystem/Scripts/Runtime/Core/CursorManager.cs) |

```csharp
using OxGKit.CursorSystem;
```

<Highlight color="#00d679">Reminder</Highlight> The instance methods of `CursorManager` correspond **one-to-one** with the [Cursors](./Cursors.mdx) static facade (the singleton accessor is `internal`); route calls through `Cursors` — there is no need to hold an instance reference yourself.

## Quick Start {#quick-start}

```csharp
using OxGKit.CursorSystem;

// The CursorManager is automatically found or created by the Cursors facade (singleton)
Cursors.InitInstance();

// After authoring Cursor States in the Inspector, switch by name
Cursors.SetCursorState("Loading");
```

## General Rules {#general-rules}

### Singleton and Lifecycle {#singleton-lifecycle}

1. The first access through [Cursors](./Cursors.mdx) automatically finds the `CursorManager` in the scene; if none exists, a `[CursorManager]` node is created automatically.
2. In `Awake`, it parents itself under the `OxGKit` container node and persists with **DontDestroyOnLoad**, and initializes the current state to the first element in the list.
3. In `Start`, it resets the rendering (applies the default state); in `Update`, it drives the current state's dynamic cursor animation according to the **Ignore Time Scale** setting.
4. `OnEnable` resets back to the default state; `OnDisable` removes the cursor rendering (restores the system cursor).

### Inspector Members {#inspector-members}

| Member | Description |
| :--- | :--- |
| `Ignore Time Scale` | Whether the dynamic cursor animation ignores `Time.timeScale` (default `true`, driven by `Time.unscaledDeltaTime`). |
| `List Cursor States` | The [CursorState](#cursorstate) list; **the first entry is the default state** (a built-in `Default` state with frameRate 30). |

## CursorState {#cursorstate}

Cursor state (serializable, nested in `CursorManager`) that defines a **single cursor state's** render type, textures, hotspot, and animation parameters. Author it in the Inspector, or get it via [Cursors.GetCursorState](./Cursors.mdx#getcursorstate) and adjust it at runtime (e.g., assign textures loaded from an AssetBundle).

|  |  |
| :--- | :--- |
| **Type** | `[Serializable] public class CursorState` |
| **Source** | [CursorManager.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/CursorSystem/Scripts/Runtime/Core/CursorManager.cs) |

### Members {#cursorstate-members}

| Member | Description |
| :--- | :--- |
| `public string stateName` | The state name (the key for runtime switching). |
| `public RenderType renderType` | Static or dynamic cursor type, default `Static`. |
| `public CursorMode cursorMode` | Cursor rendering mode (`Auto` / `ForceSoftware`), default `Auto`. |
| `public bool scalingEnabled` | Scaling toggle, default `false` (scaling is only supported in `ForceSoftware` rendering mode). |
| `public Vector2 scale` | Scale factor, default `(1, 1)` (requires `scalingEnabled` to take effect). |
| `public Vector2 hotspot` | The cursor hotspot position, default `(0, 0)`. |
| `public Texture2D staticCursorTexture` | The static cursor texture. |
| `public List<Texture2D> dynamicCursorTextures` | The dynamic cursor frame sequence. |
| `public bool isLoop` | Whether the dynamic cursor loops, default `false`. |
| `public PlayMode playMode` | The dynamic cursor play mode, default `Normal`. |
| `public int frameRate` | The dynamic cursor frame rate (FPS), field default `0` (**must be greater than 0 for the animation to play**). |

### RenderType {#rendertype}

Defines the static or dynamic cursor type.

```csharp
public enum RenderType
{
    Static, // Static cursor
    Dynamic // Dynamic cursor (frame animation)
}
```

### PlayMode {#playmode}

Defines the animation play mode.

```csharp
public enum PlayMode
{
    Normal,         // Forward
    Reverse,        // Backward
    PingPong,       // Forward -> backward
    PingPongReverse // Backward -> forward
}
```

<Highlight color="#0373fc">Attention</Highlight> With `isLoop` off, `Normal` / `Reverse` stop at the last frame; `PingPong` / `PingPongReverse` stop after **one full round trip**.


Sets the static cursor texture and **applies the render immediately**; when `t2d` is `null`, the current `staticCursorTexture` is re-applied directly (in `ForceSoftware` mode with scaling enabled, the scaled texture is applied).

```csharp
// Assign a texture at runtime (e.g., loaded from an AssetBundle)
var cursorState = Cursors.GetCursorState("Default");
cursorState.SetStaticCursor(tex);
```

### SetDynamicCursor {#state-setdynamiccursor}

```csharp
public void SetDynamicCursor(Texture2D[] t2ds)
```

Replaces the dynamic cursor frame sequence and **resets the animation parameters** (plays from the beginning).

```csharp
// Replace the frame sequence and adjust parameters at runtime
var cursorState = Cursors.GetCursorState("Loading");
cursorState.SetDynamicCursor(texture2ds);
cursorState.SetFrameRate(12);
cursorState.SetLoop(true);
cursorState.ResetRender();
```

<Highlight color="#0373fc">Attention</Highlight> [SetStaticCursor](#state-setstaticcursor) / [SetDynamicCursor](#state-setdynamiccursor) do **not** change `renderType`; to switch the state's render type, call [SetRenderType](#state-setrendertype) and then [ResetRender](#state-resetrender).
