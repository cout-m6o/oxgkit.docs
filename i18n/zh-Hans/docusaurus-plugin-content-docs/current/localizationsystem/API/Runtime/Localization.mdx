`Localization` 是 **LocalizationSystem** 的本地化核心 (成员皆为 `static`)，由项目通过**回调**提供支持语系与语言表解析 ([onAddSupportedLanguages](#onaddsupportedlanguages)、[onParsingLanguageData](#onparsinglanguagedata)、[onChangeLanguage](#onchangelanguage))，并提供**语系切换 ([ChangeLanguage](#changelanguage))**、**系统语系检测**与**代码取字 ([GetStringByCode](#getstringbycode))** API；完整初始流程可参考[模块介绍](../../intro.mdx)。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGKit.LocalizationSystem` |
| **类型** | `public class Localization` (成员皆为 `static`) |
| **源码** | [Localization.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/LocalizationSystem/Scripts/Runtime/Core/Localization.cs) |

```csharp
using OxGKit.LocalizationSystem;
```

## 快速上手 {#quick-start}

```csharp
using System.Collections.Generic;
using OxGKit.LocalizationSystem;

// 1. 声明支持语系
Localization.onAddSupportedLanguages = (supportedLanguages) =>
{
    supportedLanguages.Add(LangType.English);
    supportedLanguages.Add(LangType.ChineseTraditional);
};

// 2. 提供语言表解析 (数据来源由项目自行决定: JSON、表格导出、服务器...)
Localization.onParsingLanguageData = (langType, langData) =>
{
    foreach (var pair in langSheet[langType.ToString()])
        langData.TryAdd(pair.Key, pair.Value);
    return true; // 解析成功返回 true
};

// 3. 语系切换成功后刷新 UI 文字
Localization.onChangeLanguage = (langType) => RefreshAllLocalizedTexts();

// 4. 首次切换 (例如使用系统语系，不支持时自动回退 English)
Localization.ChangeLanguage(Localization.systemLanguage);

// 5. UI 一律通过代码取字
string title = Localization.GetStringByCode("ui.title");
```

## 通用规则 {#general-rules}

### 必须实现的回调 {#required-callbacks}

1. 赋值 [onAddSupportedLanguages](#onaddsupportedlanguages) 声明支持语系。
2. 赋值 [onParsingLanguageData](#onparsinglanguagedata) 提供语言表解析 (解表所需的数据来源需先准备完成)。
3. (建议) 订阅 [onChangeLanguage](#onchangelanguage) 刷新 UI 文字。

<Highlight color="#ff2f00">重要</Highlight> `onParsingLanguageData` **未赋值或解析返回 `false`** 时，[ChangeLanguage](#changelanguage) 会直接**抛出异常**。

### 缓存机制 {#cache-rules}

<Highlight color="#0373fc">注意</Highlight> [GetSupportedLanguages](#getsupportedlanguages) 与转译表 API **首次调用后即缓存结果** (不会再次触发回调)，因此必须**先赋值 `onAddSupportedLanguages`**，再调用任何支持语系相关 API (含 [systemLanguage](#systemlanguage)、[IsSupportedLanguage](#issupportedlanguage) 等)。

### 语系保存 {#persist-language}

<Highlight color="#00d679">提醒</Highlight> 模块**不负责保存所选语系**，由项目自行保存/还原 `LangType`，还原时建议先以 [GetAndCheckIsSupportedLanguage](#getandcheckissupportedlanguage) 校正。

### onAddSupportedLanguages {#onaddsupportedlanguages}

```csharp
public static Action<HashSet<LangType>> onAddSupportedLanguages
```

新增**支持语系**回调；于 [GetSupportedLanguages](#getsupportedlanguages) **首次**被调用时触发，将项目支持的语系加入 `supportedLanguages` 集合。

```csharp
Localization.onAddSupportedLanguages = (supportedLanguages) =>
{
    supportedLanguages.Add(LangType.English);
    supportedLanguages.Add(LangType.ChineseTraditional);
    supportedLanguages.Add(LangType.ChineseSimplified);
    supportedLanguages.Add(LangType.Japanese);
    supportedLanguages.Add(LangType.Korean);
};
```

### onParsingLanguageData {#onparsinglanguagedata}

```csharp
public static Func<LangType, Dictionary<string, string>, bool> onParsingLanguageData
```

解析**语言表数据**回调；[ChangeLanguage](#changelanguage) 时调用解析，需将指定语系的 **Code -> Text** 键值填入 `langData` (切换成功后该字典会被缓存为**当前语言表**)，解析成功返回 `true`。

```csharp
Localization.onParsingLanguageData = (langType, langData) =>
{
    // Your lang sheet (can load from json or server)
    if (langSheet.ContainsKey(langType.ToString()))
    {
        // The ref langData will be cached by Localization
        foreach (var pair in langSheet[langType.ToString()])
            langData.TryAdd(pair.Key, pair.Value);
        return true;
    }
    return false;
};
```

<Highlight color="#ff2f00">重要</Highlight> 未赋值或返回 `false` 时，`ChangeLanguage` 会抛出异常；解表所需的数据来源 (游戏数据库、下载的语言表等) 需**在初始本地化前准备完成**。

### onChangeLanguage {#onchangelanguage}

```csharp
public static Action<LangType> onChangeLanguage
```

切换**语系成功后**的通知回调，参数为切换后的语系；适合在此刷新 UI 显示文字 (搭配 [GetStringByCode](#getstringbycode))。

```csharp
private void _InitEvents()
{
    // Refresh lang text callback
    Localization.onChangeLanguage += this._RefreshLanguage;
}

private void _RefreshLanguage(LangType langType)
{
    this.titleText.text = Localization.GetStringByCode("ui.title");
}
```

<Highlight color="#00d679">提醒</Highlight> 每次切换成功都会触发，回调内容需可**重复执行** (建议仅做文字/数据重绘，勿在其中进行一次性注册)。

### systemLanguage {#systemlanguage}

```csharp
public static LangType systemLanguage { get; }
```

获取**系统语系**：将 OS 系统语言通过 [GetSystemLanguageToLangType](#getsystemlanguagetolangtype) 对应为 [LangType](#langtype)，再经 [GetAndCheckIsSupportedLanguage](#getandcheckissupportedlanguage) 检测，**不属于支持语系则一律回退 `LangType.English`**。

```csharp
// 首次进入游戏无保存语系时，以系统语系作为默认
Localization.ChangeLanguage(Localization.systemLanguage);
```

## 语系切换与取字 {#change-and-get}

### 方法总览 {#change-overview}

| 方法 | 说明 |
| :--- | :--- |
| [ChangeLanguage](#changelanguage) | 切换语系与验证语系合法性。 |
| [GetStringByCode](#getstringbycode) | 根据代码获取语言表中的对应文字。 |

---

### ChangeLanguage {#changelanguage}

```csharp
public static void ChangeLanguage(LangType langType)
```

切换语系与验证语系合法性，流程如下：

1. 调用 [onParsingLanguageData](#onparsinglanguagedata) 解析指定语系的语言表。
2. 验证 `langType` 是否属于支持语系：
   - **是**：缓存语言表数据、更新 [currentLanguage](#currentlanguage)，并触发 [onChangeLanguage](#onchangelanguage)。
   - **否**：输出警告 (`The language type is not supported`) 并**维持当前语系** (不更新、不触发回调)。

```csharp
Localization.ChangeLanguage(LangType.Japanese);

// 保存所选语系 (模块不负责保存)
PlayerPrefs.SetInt("language", (int)Localization.currentLanguage);
```

<Highlight color="#ff2f00">重要</Highlight> `onParsingLanguageData` **未赋值或解析失败 (返回 `false`)** 会抛出 `Exception`。

<Highlight color="#0373fc">注意</Highlight> 传入前可先以 [GetAndCheckIsSupportedLanguage](#getandcheckissupportedlanguage) 校正 (避免保存的旧语系值已不受支持)。

### GetStringByCode {#getstringbycode}

```csharp
public static string GetStringByCode(string code)
```

根据**代码 (Code)** 获取**当前语言表**中的对应文字；查无代码时返回 `"Unknown Text"`。

```csharp
this.titleText.text = Localization.GetStringByCode("ui.title");
```

<Highlight color="#0373fc">注意</Highlight> 尚未成功执行过 [ChangeLanguage](#changelanguage) (无语言表数据) 时会**抛出 `Exception`**；QA 验证时可将 `"Unknown Text"` 视为**缺漏字符串代码**的信号。

### GetSupportedLanguages {#getsupportedlanguages}

```csharp
public static HashSet<LangType> GetSupportedLanguages()
```

获取当前**支持语系集合**；首次调用时触发 [onAddSupportedLanguages](#onaddsupportedlanguages) 收集并**缓存**，之后直接返回缓存结果。

### IsSupportedLanguage {#issupportedlanguage}

```csharp
public static bool IsSupportedLanguage(LangType langType)
```

是否属于**支持语系**。

### GetAndCheckIsSupportedLanguage {#getandcheckissupportedlanguage}

```csharp
public static LangType GetAndCheckIsSupportedLanguage(LangType langType)
```

获取与检测是否属于支持语系类型：**支持则原值返回；不支持一律返回 `LangType.English`**。适合用于校正**保存值/系统值**。

```csharp
var savedLang = (LangType)PlayerPrefs.GetInt("language", (int)Localization.systemLanguage);
Localization.ChangeLanguage(Localization.GetAndCheckIsSupportedLanguage(savedLang));
```

### GetSystemLanguageToLangType {#getsystemlanguagetolangtype}

```csharp
public static LangType GetSystemLanguageToLangType()
```

获取 OS 系统语言 (`UnityEngine.Application.systemLanguage`) 对应的 [LangType](#langtype) 定义 (**不经**支持语系检测)；无法对应时返回 `LangType.Unspecified`。

<Highlight color="#00d679">提醒</Highlight> 部分语言 Unity `SystemLanguage` 未内置 (详见 [LangType 对照表](#langtype)的系统检测栏)，**系统检测无法返回**，但仍可作为自定义支持语系使用；`Hindi` 需 **Unity 2022.3 / Unity 6000.0 以上**才支持检测。

### GetSupportedLanguagesMappingByLangType {#getsupportedlanguagesmappingbylangtype}

```csharp
public static Dictionary<LangType, string> GetSupportedLanguagesMappingByLangType()
```

获取**支持语系**的语系文字对照表，**Key = LangType** (ex: `LangType.Spanish` -> `"Español"`)；适合用于生成语言菜单的显示文字 (首次调用后缓存)。

### GetSupportedLanguagesMappingByLangDesc {#getsupportedlanguagesmappingbylangdesc}

```csharp
public static Dictionary<string, LangType> GetSupportedLanguagesMappingByLangDesc()
```

获取**支持语系**的语系文字对照表，**Key = LangDesc** (ex: `"Español"` -> `LangType.Spanish`)；适合用于语言菜单**由选项文字反查语系**进行切换 (首次调用后缓存)。

```csharp
// 语言菜单: 以对照文字显示选项，选择后反查 LangType 进行切换
var mapping = Localization.GetSupportedLanguagesMappingByLangDesc();
Localization.ChangeLanguage(mapping["简体中文"]);
```

### GetLanguageDesc {#getlanguagedesc}

```csharp
public static string GetLanguageDesc(LangType langType)
```

获取对应的**语系文字说明** (详见 [LangType 对照表](#langtype))；未定义对照文字时返回 `"Unknown Language"`。

```csharp
string desc = LanguageMapping.GetLanguageDesc(LangType.Spanish); // "Español"
```
