**开始安装 OxGKit**

<Highlight color="#0373fc">注意</Highlight> OxGKit **皆为独立工具系统**，没有一次安装全部的必要，**需要什么装什么**，依照各模块需求安装对应的依赖即可。

## 步骤 1. (安装依赖)

**依照你要安装的模块**，先安装其依赖的第三方库 (各模块依赖请参考[步骤 2 的依赖标注](#install-modules))。

- <Highlight color="#ff2f00">1</Highlight> **[UniTask](https://github.com/Cysharp/UniTask)** (InfiniteScrollView、ActionSystem、TimeSystem、PoolSystem、Utilities 依赖)

通过 Package Manager 安装 **(Install via git)**

```
https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask
```

- <Highlight color="#ff2f00">2</Highlight> **[LWMyBox](https://github.com/michael811125/LWMyBox)** (LoggingSystem、TweenSystem、PoolSystem、Utilities 依赖)

通过 Package Manager 安装 **(Install via git)**

```
https://github.com/michael811125/LWMyBox.git
```

- <Highlight color="#ff2f00">3</Highlight> **[Unity New InputSystem](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.8/manual/index.html)** (InputSystem 依赖)

通过 Package Manager 安装 **(Install by name)**

```
com.unity.inputsystem
```

- <Highlight color="#ff2f00">4</Highlight> **[DoTween Pro](https://assetstore.unity.com/packages/tools/visual-scripting/dotween-pro-32416)** (TweenSystem 依赖，**需自行购买安装**)

- <Highlight color="#00d679">提醒</Highlight> **OxGKit.LoggingSystem** 为多数模块的共同依赖 (InfiniteScrollView、ActionSystem、NoticeSystem、InputSystem、TimeSystem、PoolSystem、Utilities)，**建议最先安装**。

```
https://github.com/michael811125/OxGKit.git?path=Assets/OxGKit/LoggingSystem/Scripts
```

---

### 方法二

**直接下载源码 ([Code Download ZIP](https://github.com/michael811125/OxGKit))**

复制所需模块的文件夹 (Assets/OxGKit/[模块名]) 到 Unity 项目的 Assets 底下。

<Highlight color="#00d679">提醒</Highlight> **如果没有要自行更改工具组的需求，建议直接使用 Package Manager 方式安装**。

## 管理组件导入 (Samples)

各模块皆附有 **Example 示例**与 **AI Agent Skills**，可通过 **Package Manager -> 选择模块 -> Samples** 进行导入。

<Highlight color="#00d679">提醒</Highlight> 有很多调用的方式，都可以参考各模块的 Samples，里面都有完整的示例。

---

## Build 激活宏

- **OXGKIT_LOGGER_ON** ([LoggingSystem](/docs/loggingsystem/intro) 日志输出开关，**发布时需在 Player Settings -> Scripting Define Symbols 加入才会输出日志**)

---

## AI 辅助开发 (AI Agent Skills) {#ai-agent-skills}

OxGKit **各系统模块**皆支持使用 **AI 编码代理** (Claude Code、OpenAI Codex CLI、Cursor、Copilot 等) 辅助开发，各模块的 Samples 内置「**AI Agent Skills**」(SKILL.md)，教导 AI 代理正确使用该模块 API。

<Highlight color="#0373fc">注意</Highlight> 完整的导入与使用说明，请参考 [AI Agent Skills](/docs/agent-skills)。
