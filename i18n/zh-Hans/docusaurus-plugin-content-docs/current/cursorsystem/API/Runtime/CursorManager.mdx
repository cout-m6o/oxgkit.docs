`CursorManager` 是 **CursorSystem** 的**游标管理器** (`MonoBehaviour` 单例)，管理 Inspector 上配置的 [CursorState](#cursorstate) 状态列表，并在 `Update` 驱动**动态游标的序列帧动画**；可通过 Samples 导入 **CursorManager Prefab** 拖拽至启动场景，或由 [Cursors](./Cursors.mdx) 门面自动创建。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGKit.CursorSystem` |
| **类型** | `[DisallowMultipleComponent] public class CursorManager : MonoBehaviour` |
| **源码** | [CursorManager.cs](https://github.com/michael811125/OxGKit/blob/master/Assets/OxGKit/CursorSystem/Scripts/Runtime/Core/CursorManager.cs) |

```csharp
using OxGKit.CursorSystem;
```

<Highlight color="#00d679">提醒</Highlight> `CursorManager` 的实例方法与 [Cursors](./Cursors.mdx) 静态门面**一一对应** (单例的获取方法为 `internal`)，建议一律通过 `Cursors` 调用，无需自行持有实例引用。

## 快速上手 {#quick-start}

```csharp
using OxGKit.CursorSystem;

// CursorManager 由 Cursors 门面自动查找或创建 (单例)
Cursors.InitInstance();

// 在 Inspector 配置 Cursor States 后，即可按名称切换
Cursors.SetCursorState("Loading");
```

## 通用规则 {#general-rules}

### 单例与生命周期 {#singleton-lifecycle}

1. 首次通过 [Cursors](./Cursors.mdx) 访问时，会自动查找场景上的 `CursorManager`；找不到则自动创建 `[CursorManager]` 节点。
2. `Awake` 时会自动整理至 `OxGKit` 容器节点下并 **DontDestroyOnLoad** 常驻，同时将当前状态初始为列表第一条。
3. `Start` 时会重置渲染 (应用默认状态)；`Update` 依 **Ignore Time Scale** 设置驱动当前状态的动态游标动画。
4. `OnEnable` 会重置回默认状态；`OnDisable` 会移除游标渲染 (恢复系统游标)。

### Inspector 成员 {#inspector-members}

| 成员 | 说明 |
| :--- | :--- |
| `Ignore Time Scale` | 动态游标动画是否忽略 `Time.timeScale` (默认 `true`，使用 `Time.unscaledDeltaTime` 驱动)。 |
| `List Cursor States` | [CursorState](#cursorstate) 状态列表，**第一条即为默认状态** (内置一条 `Default` 状态，frameRate 为 30)。 |

## CursorState {#cursorstate}

游标状态 (可序列化，嵌套于 `CursorManager`)，定义**单一游标状态**的渲染类型、贴图、热点与动画参数；可在 Inspector 上配置，也可通过 [Cursors.GetCursorState](./Cursors.mdx#getcursorstate) 获取后在运行时动态调整 (例如指定从 AssetBundle 加载的贴图)。

|  |  |
| :--- | :--- |
| **类型** | `[Serializable] public class CursorState` |
| **源码** | [CursorManager.cs](https://github.com/michael811125/OxGKit/blob/master/Assets/OxGKit/CursorSystem/Scripts/Runtime/Core/CursorManager.cs) |

### 成员 {#cursorstate-members}

| 成员 | 说明 |
| :--- | :--- |
| `public string stateName` | 状态名称 (运行时切换的依据)。 |
| `public RenderType renderType` | 静态或动态游标类型，默认 `Static`。 |
| `public CursorMode cursorMode` | Cursor 渲染模式 (`Auto` / `ForceSoftware`)，默认 `Auto`。 |
| `public bool scalingEnabled` | 缩放开关，默认 `false` (缩放仅支持 `ForceSoftware` 渲染模式)。 |
| `public Vector2 scale` | 缩放比例，默认 `(1, 1)` (需启用 `scalingEnabled` 才会生效)。 |
| `public Vector2 hotspot` | 游标热点位置，默认 `(0, 0)`。 |
| `public Texture2D staticCursorTexture` | 静态游标贴图。 |
| `public List<Texture2D> dynamicCursorTextures` | 动态游标序列帧。 |
| `public bool isLoop` | 动态游标是否循环播放，默认 `false`。 |
| `public PlayMode playMode` | 动态游标播放模式，默认 `Normal`。 |
| `public int frameRate` | 动态游标播放速率 (FPS)，字段默认 `0` (**需大于 0 动画才会播放**)。 |

### RenderType {#rendertype}

定义静态或动态游标类型。

```csharp
public enum RenderType
{
    Static, // 静态游标
    Dynamic // 动态游标 (序列帧动画)
}
```

### PlayMode {#playmode}

定义动画的播放模式。

```csharp
public enum PlayMode
{
    Normal,         // 顺放
    Reverse,        // 倒放
    PingPong,       // 顺放 -> 倒放
    PingPongReverse // 倒放 -> 顺放
}
```

<Highlight color="#0373fc">注意</Highlight> 未开启 `isLoop` 时，`Normal` / `Reverse` 播放至最后一帧即停止；`PingPong` / `PingPongReverse` 则完成**一次来回**后停止。

### SetStaticCursor {#state-setstaticcursor}

```csharp
public void SetStaticCursor(Texture2D t2d = null)
```

设置静态游标贴图并**立即应用渲染**；`t2d` 传入 `null` 时，直接以当前 `staticCursorTexture` 重新应用 (`ForceSoftware` 模式下若启用缩放，会应用缩放后的贴图)。

```csharp
// 运行时动态指定贴图 (例如从 AssetBundle 加载)

cursorState.SetStaticCursor(tex);
```

### SetDynamicCursor {#state-setdynamiccursor}

```csharp
public void SetDynamicCursor(Texture2D[] t2ds)
```

替换动态游标序列帧并**重置动画参数** (从头播放)。

```csharp
// 运行时替换序列帧与参数调整
var cursorState = Cursors.GetCursorState("Loading");
cursorState.SetDynamicCursor(texture2ds);
cursorState.SetFrameRate(12);
cursorState.SetLoop(true);
cursorState.ResetRender();
```

<Highlight color="#0373fc">注意</Highlight> [SetStaticCursor](#state-setstaticcursor) / [SetDynamicCursor](#state-setdynamiccursor) **不会**变更 `renderType`；若要切换该状态的渲染类型，请调用 [SetRenderType](#state-setrendertype) 后再 [ResetRender](#state-resetrender)。
