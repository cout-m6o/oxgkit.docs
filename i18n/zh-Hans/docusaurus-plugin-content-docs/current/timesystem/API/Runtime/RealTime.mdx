`RealTime` 是**记录应用程序启动时间的静态工具**，由主程序 (Main MonoBehaviour 的 `Awake`) 调用 `InitStartupTime()` 进行初始 (**仅首次调用生效**)，之后可通过 `timeSinceStartup` 获取启动时间，作为全局的游戏启动时间基准。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGKit.TimeSystem` |
| **类型** | `public static class RealTime` |
| **源码** | [RealTime.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/TimeSystem/Scripts/Runtime/Core/Time/RealTime.cs) |

```csharp
using OxGKit.TimeSystem;
```

## 快速上手 {#quick-start}

```csharp
using OxGKit.TimeSystem;
using UnityEngine;

public class Main : MonoBehaviour
{
    private void Awake()
    {
        // 由主程序于启动时初始 (仅首次生效)
        RealTime.InitStartupTime();
    }

    private void Start()
    {
        if (RealTime.IsInitStartupTime())
        {
            // 获取游戏启动时间
            System.DateTime startup = RealTime.timeSinceStartup;
        }
    }
}
```

<Highlight color="#00d679">提醒</Highlight> 建议在**主程序启动时**即调用 `InitStartupTime()`，记录到的才会是真正的游戏启动时间。

### InitStartupTime {#initstartuptime}

```csharp
public static void InitStartupTime()
```

以当下系统时间 (`DateTime.Now`) 记录为启动时间；**仅首次调用生效**，重复调用会直接忽略。

### IsInitStartupTime {#isinitstartuptime}

```csharp
public static bool IsInitStartupTime()
```

检查是否已初始启动时间；尚未初始时会通过日志提示 (`Please call RealTime.InitStartupTime() in main program first`) 并返回 false。
