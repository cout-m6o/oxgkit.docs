## 基本说明

补间动画 (仅支持 [DoTween Pro](https://assetstore.unity.com/packages/tools/visual-scripting/dotween-pro-32416))，通过 Inspector 配置**补间轨道** (Position、Rotation、Scale、Size、Alpha、Color)，支持 **Normal、Reverse、PingPong、Sequence** 播放模式与**编辑器预览 (Preview Mode)**，并可搭配 **DoTweenAnimEvent** 以 **Parallel 或 Sequence** 模式分组播放多个 DoTweenAnim (带结束回调)。

- 版本：**v1.0.4** (`com.michaelo.oxgkit.tweensystem`)
- 命名空间：`OxGKit.TweenSystem`

主要组件 (Add Component)：

- Add Component/OxGKit/TweenSystem/**DoTweenAnim**
- Add Component/OxGKit/TweenSystem/**DoTweenAnimEvent**

<Highlight color="#0373fc">注意</Highlight> 本模块依赖 **DoTween Pro (需自行购买安装)**、**LWMyBox** 与 **OxGKit.TimeSystem**，需先安装依赖库 (详见 Installation)。

## 应用说明

### 补间轨道 (Tween Tracks)

**DoTweenAnim** 可于 Inspector 启用以下补间轨道 (可复选)，各轨道皆可独立配置起止值 (或 Sequence 序列点位)、时长 (duration)、缓动 (easeMode)、播放模式 (playMode) 与循环 (loopTimes / loopType)：

| 轨道开关 | 补间目标 | 需求组件 (自动查找) |
| :--- | :--- | :--- |
| `tPositionOn` | 位置 (Position) | Transform |
| `tRotationOn` | 旋转 (Rotation) | Transform |
| `tScaleOn` | 缩放 (Scale) | Transform |
| `tSizeOn` | 尺寸 (Size) | RectTransform |
| `tAlphaOn` | 透明度 (Alpha) | CanvasGroup |
| `tImgColorOn` | 图片颜色 (Image Color) | Image |
| `tSprColorOn` | 精灵颜色 (Sprite Color) | SpriteRenderer |

### 播放模式 (PlayMode)

- **Normal**：正向播放 (from → to)。
- **Reverse**：反向播放 (to → from)。
- **PingPong**：来回播放 (from → to → from)。
- **Sequence**：依**序列点位列表**依序播放 (此模式下 from / to 不生效)。

### 驱动模式 (DriveMode)

- **Active**：GameObject **激活时自动播放** (SetActive 驱动)，支持循环 (Loop) 与间隔重播 (Interval)。
- **Event**：由 **DoTweenAnimEvent 或代码**调用播放 (trigger 控制正反向)，适合 UI 开关动画。

## 简单使用

### 分组播放 (DoTweenAnimEvent)

将多个 **DoTweenAnim** (DriveMode 设为 **Event**) 拖拽至 **DoTweenAnimEvent** 的列表中，即可由代码统一播放：

```csharp
using DG.Tweening;
using OxGKit.TweenSystem;
using UnityEngine;

public class PanelController : MonoBehaviour
{
    [SerializeField]
    private DoTweenAnimEvent _panelAnim;

    // 开启面板 (正向播放)
    public void OpenPanel()
    {
        this._panelAnim.PlayNormal(() => Debug.Log("Panel opened"));
    }

    // 关闭面板 (反向播放)
    public void ClosePanel()
    {
        this._panelAnim.PlayReverse(() => this.gameObject.SetActive(false));
    }

    // 触发切换 (每次调用正反向交替)
    public void TogglePanel()
    {
        this._panelAnim.PlayTrigger();
    }
}
```
