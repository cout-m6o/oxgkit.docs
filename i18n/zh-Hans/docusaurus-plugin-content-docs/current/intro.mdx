## 基本说明

OxGKit 是基于 Unity 设计于游戏开发常用的系统工具组 (**皆为独立工具**)，需要什么装什么，各系统模块可通过 UPM 单独安装、单独使用，彼此互不强制绑定。

<Highlight color="#00d679">提醒</Highlight> 部分模块依赖 [LoggingSystem](/docs/loggingsystem/intro)，因为必要时，有日志整合输出的需求 (由 LoggingLauncher 统一控管各模块日志的开关与级别)。

**目前包含以下**

- [日志系统 (LoggingSystem)](/docs/loggingsystem/intro)
- [无限列表 (InfiniteScrollView)](/docs/infinitescrollview/intro)
- [动作序列系统 (ActionSystem)](/docs/actionsystem/intro)
- [通知系统 (NoticeSystem)](/docs/noticesystem/intro)
- [输入控制系统 (InputSystem)](/docs/inputsystem/intro)
- [补间动画系统 (TweenSystem)](/docs/tweensystem/intro)

## 工具组特点

- **独立模块化**

  皆为独立工具系统，通过 UPM 各自安装、各自升级，需要什么装什么，不会强迫引入用不到的模块，也可以搭配 [OxGFrame](https://github.com/michael811125/OxGFrame) 框架一起使用。

- **轻量依赖**

  各模块依赖极少 (部分模块依赖 [UniTask](https://github.com/Cysharp/UniTask)、[LWMyBox](https://github.com/michael811125/LWMyBox) 与 OxGKit.LoggingSystem)，安装清单一目了然。

- **完整示例**

  各模块皆附有 Example (通过 Package Manager -> Samples 导入)，可以直接参考示例快速上手。

- **AI 辅助开发 (AI Agent Skills)**

  各系统模块皆内置 **AI Agent Skills** (SKILL.md)，教导 AI 编码代理 (Claude Code、OpenAI Codex CLI、Cursor、Copilot 等) 正确使用各模块 API，详细说明请参考 [AI Agent Skills](/docs/agent-skills)。

- **模板创建菜单**

  部分模块提供 Right-Click Create/OxGKit/... 脚本模板菜单 (例如 ActionSystem、NoticeSystem、InputSystem、InfiniteScrollView 等)，快速创建实现脚本。
