`LoggingLauncher` 是 **LoggingSystem** 的日志部署启动器 (`MonoBehaviour` 单例)，负责**日志器的初始与加载配置文件** (StreamingAssets)，并提供**全局 (Master) 与个别日志器的动态配置 API**；可通过 Samples 导入 **LoggingLauncher Prefab** 拖拽至场景激活 (仅需激活一次)。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGKit.LoggingSystem` |
| **类型** | `public class LoggingLauncher : MonoBehaviour` |
| **源码** | [LoggingLauncher.cs](https://github.com/michael811125/OxGKit/blob/master/Assets/OxGKit/LoggingSystem/Scripts/Runtime/LoggingLauncher.cs) |

```csharp
using OxGKit.LoggingSystem;
```

<Highlight color="#0373fc">注意</Highlight> 标注 **[StartCoroutine]** 的方法为包装协程的便捷调用；各方法皆有对应的 **[Async]** 版本 (`IEnumerator`)，可自行以协程等待完成时机。

## 快速上手 {#quick-start}

```csharp
using OxGKit.LoggingSystem;

// 场景上已放置 LoggingLauncher Prefab (Initialize On Awake)
// -> 会自动 InitLoggers + 加载 StreamingAssets 配置文件

// 动态配置单一日志器
LoggingLauncher.ConfigureLogger("Game.Logger", true, LogLevel.LogWarning | LogLevel.LogError);

// 全局开关
LoggingLauncher.ToggleMasterLogging(false);

// 自定义配置 (动态配置日志器)
var loggersConfig = new LoggersConfig
(
    new LoggerSettings("Game.Logger", true, LogLevel.All)
);
LoggingLauncher.SetLoggersConfig(loggersConfig);
```

## 通用规则 {#general-rules}

### 初始流程 {#init-flow}

1. **Initialize On Awake (默认)**：LoggingLauncher 于 `Awake` 自动执行 `InitLoggers` (反射收集所有 `Logging` 实现) 并尝试加载 StreamingAssets 配置文件。
2. **手动初始 (HybridCLR)**：取消 Inspector 上的 **"Initialize On Awake"** 选项，自行调用 [CreateLogger](#createlogger) 逐一注册，最后调用 [TryLoadLoggers](#tryloadloggers) 应用配置。

<Highlight color="#ff2f00">重要</Highlight> 搭配 **HybridCLR** 有主工程跟热更工程的区分时，必须手动拆分创建 **AOT** 跟 **Hotfix** 的 Loggers 初始流程 (Hotfix 工程的 Loggers 需在 Hotfix 工程中初始)。

### 配置生效条件 {#config-condition}

<Highlight color="#ff2f00">重要</Highlight> 仅于 **UNITY_EDITOR** 或已定义 **OXGKIT_LOGGER_ON** 宏时，才会进行日志器加载与输出，否则会提示 `Not enabled LoggingSystem by symbol [OXGKIT_LOGGER_ON]`。

## 日志器管理 {#logger-management}

### 方法总览 {#logger-overview}

| 方法 | 说明 |
| :--- | :--- |
| [InitLoggers](#initloggers) | 反射收集并初始所有日志器。 |
| [ClearLoggers](#clearloggers) | 清除所有已注册日志器。 |

### InitLoggers {#initloggers}

```csharp
public static void InitLoggers()
```

以反射收集所有 `Logging` 实现类并创建实例 (含 [LoggerName](./LoggersConfig.mdx#loggernameattribute) 的名称与覆写处理)。

### ClearLoggers {#clearloggers}

```csharp
public static void ClearLoggers()
```

清除所有已注册的日志器缓存。

### CreateLogger {#createlogger}

```csharp
public static void CreateLogger<TLogging>() where TLogging : Logging, new()
```

手动注册单一日志器，用于 **HybridCLR** 手动拆分 AOT / Hotfix 初始流程 (避免反射收集不到热更工程的类型)。

```csharp
// HybridCLR (必须取消 LoggingLauncher 上的 "Initialize On Awake" 选项):
LoggingLauncher.CreateLogger<LoggingDemoLogger1>();
LoggingLauncher.CreateLogger<LoggingDemoLogger2>();
LoggingLauncher.TryLoadLoggers();
```

### TryInitLoggers {#tryinitloggers}

```csharp
// [StartCoroutine]
public static void TryInitLoggers()

// [Async]
public static IEnumerator TryInitLoggersAsync()
```

初始所有日志器 (`InitLoggers`) 并加载 StreamingAssets 配置文件应用设置 (等同 Awake 自动初始流程)。

### TryLoadLoggers {#tryloadloggers}

```csharp
// [StartCoroutine]
public static void TryLoadLoggers()

// [Async]
public static IEnumerator TryLoadLoggersAsync()
```

依配置文件**重载**日志器设置；**新增或移除 Logger 后皆需调用此方法进行重载**。

