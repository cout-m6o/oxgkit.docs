`LoggingHelper` 为 **LoggingSystem** 的 Editor 辅助工具，提供**配置文件的创建、写入与格式转换** (BYTES [Cipher] 与 JSON [Plaintext])，额外有需要编写 BuildTool 的可以调用。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGKit.LoggingSystem.Editor` |
| **类型** | `public static class LoggingHelper` |
| **源码** | [LoggingHelper.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/LoggingSystem/Scripts/Editor/LoggingHelper.cs) |

```csharp
using OxGKit.LoggingSystem.Editor;
```

## 菜单功能 (Menu Items) {#menu-items}

| 菜单 | 说明 |
| :--- | :--- |
| `Assets/Create/OxGKit/Logging System/[JSON - Plaintext] Create LoggerConfig.dat (In StreamingAssets)` | 创建 **JSON (明文)** 配置文件至 StreamingAssets。 |
| `Assets/Create/OxGKit/Logging System/[BYTES - Cipher] Create LoggerConfig.dat (In StreamingAssets)` | 创建 **BYTES (加密)** 配置文件至 StreamingAssets。 |
| `Assets/OxGKit/Logging System/Convert LoggerConfig.dat (BYTES [Cipher] <-> JSON [Plaintext])` | 对选中的 StreamingAssets 配置文件进行**格式互转**。 |

<Highlight color="#00d679">提醒</Highlight> 发布建议使用 **Cipher**；配置文件名称与扩展名可通过 [LoggingSettings](../Runtime/LoggersConfig.mdx#loggingsettings) 定制。

## 方法 {#methods}

### WriteConfig {#writeconfig}

```csharp
public static void WriteConfig(LoggersConfig loggersConfig, ConfigFileType configFileType = ConfigFileType.Bytes)
```

将 [LoggersConfig](../Runtime/LoggersConfig.mdx) 依指定的 [ConfigFileType](../Runtime/LoggersConfig.mdx#configfiletype) 写入 StreamingAssets 配置文件。

```csharp
using OxGKit.LoggingSystem;
using OxGKit.LoggingSystem.Editor;

// BuildTool 示例：构建前输出加密配置
var loggersConfig = new LoggersConfig();
LoggingLauncher.ReloadLoggersConfigAndSet(loggersConfig, (result) =>
{
    LoggingHelper.WriteConfig(result, ConfigFileType.Bytes);
});
```
