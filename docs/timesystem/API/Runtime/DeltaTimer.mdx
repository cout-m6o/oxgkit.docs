`DeltaTimer` 是以**外部餵入的 deltaTime 累加**驅動的計時器 (遊戲時間)，需由擁有者 (MonoBehaviour 的 `Update` 等) **持續呼叫 `UpdateTimer(dt)` 驅動**；停止餵入即凍結，餵入 `Time.deltaTime` 時自然跟隨 `Time.timeScale` 與遊戲暫停。支持 **Timer (單次計時)**、**Tick (循環計時)**、**Mark (時間標記)** 三種模式與時間速度調整。

|  |  |
| :--- | :--- |
| **命名空間** | `OxGKit.TimeSystem` |
| **類型** | `public class DeltaTimer` |
| **原始碼** | [DeltaTimer.cs](https://github.com/michael811125/OxGKit/blob/master/Assets/OxGKit/TimeSystem/Scripts/Runtime/Core/Timer/DeltaTimer.cs) |

```csharp
using OxGKit.TimeSystem;
```

## 快速上手 {#quick-start}

```csharp
using OxGKit.TimeSystem;
using UnityEngine;

public class SkillCooldown : MonoBehaviour
{
    private DeltaTimer _cooldown;

    private void Start()
    {
        // 建立並自動播放 (autoPlay: true)
        this._cooldown = new DeltaTimer(true);
        // 設置 3 秒冷卻
        this._cooldown.SetTimer(3f);
    }

    private void Update()
    {
        // 必須持續餵入 deltaTime 驅動計時器
        this._cooldown.UpdateTimer(Time.deltaTime);

        if (this._cooldown.IsTimerTimeout())
        {
            // 冷卻結束 (時間到)
        }
    }
}
```

## 通用規則 {#general-rules}

### DeltaTimer vs RealTimer {#deltatimer-vs-realtimer}

<Highlight color="#0373fc">注意</Highlight> `DeltaTimer` 的時間**僅在被餵入 `UpdateTimer(dt)` 時前進**，餵入 `Time.deltaTime` 時會跟隨 `Time.timeScale` 與遊戲暫停 (凍結)；[RealTimer](./RealTimer.mdx) 則以**系統時鐘**計算，即使遊戲暫停仍持續計時，請依情境選用 (詳見[模組選型](../../intro.mdx#模組選型-依時間基準區分))。

### 播放狀態 {#playback-state}

<Highlight color="#ff2f00">重要</Highlight> 計時器建構後**預設為停止狀態**，需呼叫 [Play](#play) (或使用建構子 `autoPlay: true`) 才會開始計時。

<Highlight color="#00d679">提醒</Highlight> [Stop](#stop) 會清空所有計時數據 (保留時間速度)；[Reset](#reset) 會連同時間速度一併重置為預設值；[Pause](#pause) 僅暫停，可由 [Play](#play) 續播。

### UpdateTimer {#updatetimer}

```csharp
public void UpdateTimer(float dt)
```

需要透過 MonoBehaviour 的 `Update` **持續餵入 deltaTime** 驅動計時器 (內部進行累加)。

```csharp
private void Update()
{
    this._deltaTimer.UpdateTimer(Time.deltaTime);
}
```

<Highlight color="#ff2f00">重要</Highlight> 停止餵入 = 計時凍結，所有 Timer / Tick / Mark 的判斷皆不會前進。

### Play {#play}

```csharp
public void Play()
```

開始計時或自暫停狀態**續播** (會扣除暫停期間的時間，不會跳段)。

### Pause {#pause}

```csharp
public void Pause()
```

暫停計時，記錄暫停時間點，可由 [Play](#play) 續播。

### Stop {#stop}

```csharp
public void Stop()
```

停止計時並**清空所有計時數據** (Timer / Tick / Mark 設置皆歸零)，但**保留時間速度** (timeSpeed)。

### Reset {#reset}

```csharp
public void Reset()
```

重置所有狀態為預設值 (含**時間速度重置為 1**)，並回到停止狀態。

### IsPlaying {#isplaying}

```csharp
public bool IsPlaying()
```

返回是否正在計時中。

### IsPause {#ispause}

```csharp
public bool IsPause()
```

返回是否為暫停 (非播放) 狀態。

### GetTime {#gettime}

```csharp
public float GetTime()
```

取得計時器的**當前累計時間 (秒)**，計時中會受 [SetTimeSpeed](#settimespeed) 影響；暫停時返回暫停當下的時間。

### SetTimeSpeed {#settimespeed}

```csharp
public void SetTimeSpeed(float timeSpeed)
```

設置時間運轉速度 (預設 1)，影響 [GetTime](#gettime) 的時間流速 (連帶影響 Timer / Tick / Mark 判斷)。

### GetTimeSpeed {#gettimespeed}

```csharp
public float GetTimeSpeed()
```

## Timer 單次計時 {#timer}

依照設置的秒數進行**單次倒數計時**。

### 方法總覽 {#timer-overview}

| 方法 | 說明 |
| :--- | :--- |
| [SetTimer](#settimer) | 設置要計時的秒數。 |
| [TimerCountdown](#timercountdown) | 取得倒數剩餘秒數 (到時返回 0)。 |
| [IsTimerTimeout](#istimertimeout) | 返回計時時間是否已經到了。 |
| [GetTimerCountdownRatio](#gettimercountdownratio) | 取得倒數時間比率 (1 遞減至 0)。 |

---

### SetTimer {#settimer}

```csharp
public void SetTimer(float timeSeconds)
```

設置要計時的秒數 (以當前時間 + 秒數作為觸發時間點)。

```csharp
this._deltaTimer.SetTimer(3f);
this._deltaTimer.Play();
```

### TimerCountdown {#timercountdown}

```csharp
public float TimerCountdown()
```

計算觸發時間的倒數剩餘秒數，如果已超過設置的觸發時間將直接返回 0。

### IsTimerTimeout {#istimertimeout}

```csharp
public bool IsTimerTimeout()
```

返回計時時間是否已經到了 (超過觸發時間點返回 true)。

<Highlight color="#00d679">提醒</Highlight> 時間到後 `IsTimerTimeout()` 會**持續返回 true**，一次性行為請於觸發後自行 [Stop](#stop) 或重新 [SetTimer](#settimer)。

### GetTimerCountdownRatio {#gettimercountdownratio}

```csharp
public float GetTimerCountdownRatio()
```

取得 Timer 倒數計時的時間比率，**1 遞減至 0，0 = 時間到** (適合驅動進度條 UI)。

## Tick 循環計時 {#tick}

持續依照設置的間隔秒數**循環觸發** (Timeout 後自動重新裝填)。

### 方法總覽 {#tick-overview}

| 方法 | 說明 |
| :--- | :--- |
| [SetTick](#settick) | 設置 Tick 間隔秒數。 |
| [GetTick](#gettick) | 取得設置的 Tick 間隔秒數。 |
| [TickCountdown](#tickcountdown) | 取得本次 Tick 的倒數剩餘秒數。 |
| [IsTickTimeout](#isticktimeout) | 返回 Tick 時間是否已經到了 (自動重新裝填)。 |
| [GetTickCountdownRatio](#gettickcountdownratio) | 取得 Tick 倒數時間比率 (1 遞減至 0)。 |

---

### SetTick {#settick}

```csharp
public void SetTick(float tickSeconds)
```

設置 Tick 間隔秒數，當 [IsTickTimeout](#isticktimeout) 觸發後仍會**持續循環 Tick**。

```csharp
// 每 0.5 秒觸發一次
this._deltaTimer.SetTick(0.5f);
this._deltaTimer.Play();
```

### GetTick {#gettick}

```csharp
public float GetTick()
```

取得設置的 Tick 間隔秒數。

### TickCountdown {#tickcountdown}

```csharp
public float TickCountdown()
```

取得本次 Tick 觸發時間的倒數剩餘秒數，如果已超過觸發時間將直接返回 0。

### IsTickTimeout {#isticktimeout}

```csharp
public bool IsTickTimeout()
```

返回 Tick 時間是否已經到了；返回 true 時會**自動以當前時間重新裝填下一次 Tick**，形成循環觸發。

```csharp
private void Update()
{
    this._deltaTimer.UpdateTimer(Time.deltaTime);

    if (this._deltaTimer.IsTickTimeout())
    {
        // 每個 Tick 週期觸發一次
    }
}
```

<Highlight color="#ff2f00">重要</Highlight> `IsTickTimeout()` 返回 true 時會**自動重新裝填**，該次觸發即被「消耗」，**同一週期內請僅由單一呼叫端檢查一次**，否則觸發會被其他呼叫端吃掉。

### GetTickCountdownRatio {#gettickcountdownratio}

```csharp
public float GetTickCountdownRatio()
```

取得 Tick 倒數計時的時間比率，**1 遞減至 0，0 = 時間到**。

### GetElapsedMarkTime {#getelapsedmarktime}

```csharp
public float GetElapsedMarkTime()
```

取得自上次標記以來的經過時間 (秒)，尚未超過標記時間點時返回 0。

```csharp

```
