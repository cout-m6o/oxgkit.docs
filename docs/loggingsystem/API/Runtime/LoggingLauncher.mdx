`LoggingLauncher` 是 **LoggingSystem** 的日誌部署啟動器 (`MonoBehaviour` 單例)，負責**日誌器的初始與載入配置文件** (StreamingAssets)，並提供**全域 (Master) 與個別日誌器的動態配置 API**；可透過 Samples 匯入 **LoggingLauncher Prefab** 拖曳至場景激活 (僅需激活一次)。

|  |  |
| :--- | :--- |
| **命名空間** | `OxGKit.LoggingSystem` |
| **類型** | `public class LoggingLauncher : MonoBehaviour` |
| **原始碼** | [LoggingLauncher.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/LoggingSystem/Scripts/Runtime/LoggingLauncher.cs) |

```csharp
using OxGKit.LoggingSystem;
```

<Highlight color="#0373fc">注意</Highlight> 標註 **[StartCoroutine]** 的方法為包裝協程的便捷呼叫；各方法皆有對應的 **[Async]** 版本 (`IEnumerator`)，可自行以協程等待完成時機。

## 快速上手 {#quick-start}

```csharp
using OxGKit.LoggingSystem;

// 場景上已放置 LoggingLauncher Prefab (Initialize On Awake)
// -> 會自動 InitLoggers + 加載 StreamingAssets 配置文件

// 動態配置單一日誌器
LoggingLauncher.ConfigureLogger("Game.Logger", true, LogLevel.LogWarning | LogLevel.LogError);

// 全域開關
LoggingLauncher.ToggleMasterLogging(false);

// 自定義配置 (動態配置日誌器)
var loggersConfig = new LoggersConfig
(
    new LoggerSettings("Game.Logger", true, LogLevel.All)
);
LoggingLauncher.SetLoggersConfig(loggersConfig);
```

## 通用規則 {#general-rules}

### 初始流程 {#init-flow}

1. **Initialize On Awake (預設)**：LoggingLauncher 於 `Awake` 自動執行 `InitLoggers` (反射收集所有 `Logging` 實作) 並嘗試加載 StreamingAssets 配置文件。
2. **手動初始 (HybridCLR)**：取消 Inspector 上的 **"Initialize On Awake"** 選項，自行呼叫 [CreateLogger](#createlogger) 逐一註冊，最後呼叫 [TryLoadLoggers](#tryloadloggers) 套用配置。

<Highlight color="#ff2f00">重要</Highlight> 搭配 **HybridCLR** 有主工程跟熱更工程的區分時，必須手動拆分創建 **AOT** 跟 **Hotfix** 的 Loggers 初始流程 (Hotfix 工程的 Loggers 需在 Hotfix 工程中初始)。

### 配置生效條件 {#config-condition}

<Highlight color="#ff2f00">重要</Highlight> 僅於 **UNITY_EDITOR** 或已定義 **OXGKIT_LOGGER_ON** 宏時，才會進行日誌器載入與輸出，否則會提示 `Not enabled LoggingSystem by symbol [OXGKIT_LOGGER_ON]`。

### InitLoggers {#initloggers}

```csharp
public static void InitLoggers()
```

以反射收集所有 `Logging` 實作類並建立實例 (含 [LoggerName](./LoggersConfig.mdx#loggernameattribute) 的名稱與覆寫處理)。

### ClearLoggers {#clearloggers}

```csharp
public static void ClearLoggers()
```

清除所有已註冊的日誌器緩存。

### CreateLogger {#createlogger}

```csharp
public static void CreateLogger<TLogging>() where TLogging : Logging, new()
```

手動註冊單一日誌器，用於 **HybridCLR** 手動拆分 AOT / Hotfix 初始流程 (避免反射收集不到熱更工程的類型)。

```csharp
// HybridCLR (必須取消 LoggingLauncher 上的 "Initialize On Awake" 選項):
LoggingLauncher.CreateLogger<LoggingDemoLogger1>();
LoggingLauncher.CreateLogger<LoggingDemoLogger2>();
LoggingLauncher.TryLoadLoggers();
```

### TryInitLoggers {#tryinitloggers}

```csharp
// [StartCoroutine]
public static void TryInitLoggers()

// [Async]
public static IEnumerator TryInitLoggersAsync()
```

初始所有日誌器 (`InitLoggers`) 並加載 StreamingAssets 配置文件套用設定 (等同 Awake 自動初始流程)。

### TryLoadLoggers {#tryloadloggers}

```csharp
// [StartCoroutine]
public static void TryLoadLoggers()

// [Async]
public static IEnumerator TryLoadLoggersAsync()
```

依配置文件**重載**日誌器設定；**新增或移除 Logger 後皆需呼叫此方法進行重載**。

    new LoggerSettings("LoggingDemo.Logger2", true, LogLevel.LogWarning),
