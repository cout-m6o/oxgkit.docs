`LoggersConfig` 為 **LoggingSystem** 的日誌器配置數據 (可序列化)，包含**全域開關/級別/顏色**與**各日誌器 ([LoggerSettings](#loggersettings)) 設定清單**；配置可儲存為 StreamingAssets 配置文件 (Cipher/Plaintext)，或於運行時透過 [LoggingLauncher.SetLoggersConfig](./LoggingLauncher.mdx#setloggersconfig) 動態套用。

|  |  |
| :--- | :--- |
| **命名空間** | `OxGKit.LoggingSystem` |
| **類型** | `[Serializable] public class LoggersConfig` |
| **原始碼** | [LoggersConfig.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/LoggingSystem/Scripts/Runtime/Logging/Config/LoggersConfig.cs) |

```csharp
using OxGKit.LoggingSystem;
```

## 快速上手 {#quick-start}

```csharp
// 建立配置 (可傳入多組 LoggerSettings)
var loggersConfig = new LoggersConfig
(
    new LoggerSettings("Game.Logger", true, LogLevel.All),
    new LoggerSettings("Net.Logger", true, LogLevel.LogError, LogColor.Enabled)
);

// 套用配置並重載
LoggingLauncher.SetLoggersConfig(loggersConfig);
```

## LogLevel {#loglevel}

日誌級別 (**Flags**，可以 `|` 組合多個級別)。

```csharp
[Flags]
public enum LogLevel
{
    Off = 0,
    LogDebug = 1 << 0,
    LogInfo = 1 << 1,
    LogWarning = 1 << 2,
    LogError = 1 << 3,
    LogException = 1 << 4,
    All = ~0
}
```

```csharp
// 組合範例：僅輸出 Warning + Error
LoggingLauncher.ConfigureLogger("Game.Logger", true, LogLevel.LogWarning | LogLevel.LogError);
```

<Highlight color="#0373fc">注意</Highlight> 生效規則為**全域與個別取交集** (G ∩ P)，詳見[級別規則表](../../intro.mdx#log-level-級別)。

## LogColor {#logcolor}

日誌顏色模式。

```csharp
public enum LogColor
{
    Disabled = 0,   // 不啟用顏色
    Enabled = 1,    // 一律啟用顏色
    EditorOnly = 2  // 只在 Editor 啟用顏色 (釋出時自動剔除)
}
```

<Highlight color="#0373fc">注意</Highlight> 生效規則為**全域與個別取較嚴格者**，詳見[顏色規則表](../../intro.mdx#log-color-顏色)。

## LoggerNameAttribute {#loggernameattribute}

日誌器名稱標記，用於**自定義日誌器名稱**與**覆寫同名日誌器** (Override)。

|  |  |
| :--- | :--- |
| **類型** | `[AttributeUsage(AttributeTargets.Class)] public class LoggerNameAttribute : Attribute` |
| **原始碼** | [LoggerNameAttribute.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/LoggingSystem/Scripts/Runtime/Logging/Attribute/LoggerNameAttribute.cs) |

| 成員 | 說明 |
| :--- | :--- |
| `public string loggerName` | 日誌器名稱。 |
| `public bool isOverride` | 是否覆寫同名日誌器。 |

```csharp
public LoggerNameAttribute(string loggerName)
public LoggerNameAttribute(string loggerName, bool isOverride)
```

```csharp
[LoggerName("MyLogger")]
public class MyLogger1 : Logging { }

// Use same name to override MyLogger1
[LoggerName("MyLogger", true)]
public class OverrideMyLogger1 : Logging { }
```

## LoggingSettings {#loggingsettings}

LoggingSystem 的設定檔 (`ScriptableObject`)，可自定義**配置文件名稱、擴展名與加密金鑰**。

|  |  |
| :--- | :--- |
| **類型** | `public class LoggingSettings : ScriptableObject` |
| **原始碼** | [LoggingSettings.cs](https://github.com/cout-m6o/OxGKit/blob/master/Assets/OxGKit/LoggingSystem/Scripts/Runtime/Logging/ScriptableObject/LoggingSettings.cs) |

| 成員 | 說明 |
| :--- | :--- |
| `public const short CIPHER_HEADER` | 配置文件頭標 (`0x584F`)。 |
| `public byte cipher` | 配置文件金鑰，預設 `0x42`。 |
| `public string loggerCfgName` | 配置文件名稱，預設 `"LoggerConfig"`。 |
| `public string loggerCfgExtension` | 配置文件擴展名 (**需包含點**，如 `.dat`、`.cfg`、`.json`)，預設 `".dat"`。 |
| `public static LoggingSettings settings` | 設定檔單例 (自動從 `Resources` 加載，無則使用預設值)。 |

<Highlight color="#00d679">提醒</Highlight> 透過 Right-Click **Create/OxGKit/Create Settings/Create Logging Settings in Resources** 建立設定檔資源，即可客製化配置文件名稱。
