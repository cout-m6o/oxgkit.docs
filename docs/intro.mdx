## 基本說明

OxGKit 是基於 Unity 設計於遊戲開發常用的系統工具組 (**皆為獨立工具**)，需要什麼裝什麼，各系統模組可透過 UPM 單獨安裝、單獨使用，彼此互不強制綁定。

<Highlight color="#00d679">提醒</Highlight> 部分模組依賴 [LoggingSystem](/docs/loggingsystem/intro)，因為必要時，有日誌整合輸出的需求 (由 LoggingLauncher 統一控管各模組日誌的開關與級別)。

## 工具組特點

- **獨立模組化**

  皆為獨立工具系統，透過 UPM 各自安裝、各自升級，需要什麼裝什麼，不會強迫引入用不到的模組，也可以搭配 [OxGFrame](https://github.com/cout-m6o/OxGFrame) 框架一起使用。

- **輕量依賴**

  各模組依賴極少 (部分模組依賴 [UniTask](https://github.com/Cysharp/UniTask)、[LWMyBox](https://github.com/cout-m6o/LWMyBox) 與 OxGKit.LoggingSystem)，安裝清單一目了然。

- **完整範例**

  各模組皆附有 Example (透過 Package Manager -> Samples 匯入)，可以直接參考範例快速上手。

- **AI 輔助開發 (AI Agent Skills)**

  各系統模組皆內建 **AI Agent Skills** (SKILL.md)，教導 AI 編碼代理 (Claude Code、OpenAI Codex CLI、Cursor、Copilot 等) 正確使用各模組 API，詳細說明請參考 [AI Agent Skills](/docs/agent-skills)。

- **模板建立選單**

  部分模組提供 Right-Click Create/OxGKit/... 腳本模板選單 (例如 ActionSystem、NoticeSystem、InputSystem、InfiniteScrollView 等)，快速建立實作腳本。
